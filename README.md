# 💸 Control de Gastos

Página web para llevar el registro de tus gastos en **dólares ($)** y en **bolívares (Bs)**, pensada para Venezuela pero útil en cualquier parte. Funciona 100 % en tu navegador, sin cuentas de terceros y sin necesidad de un servidor.

> 🔒 **Privacidad:** todos tus datos se guardan en el **localStorage** de tu navegador. No se envían a ningún servidor ni a terceros.

---

## ✨ Características

- 💸 **Control de Gastos** — registra cada gasto con fecha, categoría, comentario y hasta una **foto del recibo** (desde tu galería o la cámara del teléfono).
- 📊 **Estadísticas** — comparativa mensual (este mes vs. anterior), gráfico de pastel por categoría, gasto por día y mini-gráficos de tendencia por categoría.
- 🧮 **Calculadora** — conversión instantánea $ ⇄ Bs con la tasa del día o la del **Dólar BCV**.
- 📅 **Calendario** — anota pagos y fechas importantes, con recordatorios y notificaciones del sistema.
- 📋 **Actividad** — registro de quién agregó, editó o eliminó cada movimiento.
- 🏷️ **Categorías propias** — crea las tuyas además de las predefinidas.
- 🎯 **Presupuesto mensual** — barra de avance (verde / naranja / rojo).
- 💱 **Moneda de referencia configurable** — elige $ o Bs como tu base principal.
- 📤 **Exportación** — a **Excel**, a **PDF**, a calendario **.ics** (Google/Apple) y respaldo completo en **JSON** (importable).
- 👤 **Múltiples cuentas** — cada cuenta tiene sus propios datos, temas y colores.
- 🎨 **Personalización** — temas claro/oscuro, color de acento y tipografía.

---

## 🚀 Cómo usarla

1. Abre `index.html` en tu navegador (o en la URL de GitHub Pages).
2. Crea una cuenta en **Crear cuenta** (usuario, contraseña y PIN de recuperación).
3. Ve a **💸 Control de Gastos** y pulsa **Agregar** para registrar tu primer gasto.
4. Explora las demás pestañas: Estadísticas, Calculadora, Calendario, Actividad y el **📖 Manual** integrado.

> 📖 La página incluye un **Manual de usuario** completo (pestaña "📖 Manual") con conceptos, ejemplos y preguntas frecuentes.

## ☁️ Desplegar en GitHub Pages

1. Sube los archivos de este proyecto a un repositorio de GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, elige la rama `main` (o `master`) y la carpeta raíz (root).
4. Guarda y espera unos segundos; la página estará disponible en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

No hace falta compilar nada: es HTML + CSS + JavaScript puro.

---

## 🛠️ Requisitos y notas

- Funciona en navegadores modernos (Chrome, Edge, Firefox, Safari) en escritorio y móvil.
- Solo necesita internet para cargar las **fuentes** (Google Fonts) y el **Dólar BCV** (ve.dolarapi.com). El resto funciona offline.
- Los datos se guardan en tu navegador: si los borras o cambias de dispositivo, se pierden. Usa **📦 Respaldar** para conservarlos.
- El dólar BCV es orientativo: siempre puedes escribir tu propia tasa.
